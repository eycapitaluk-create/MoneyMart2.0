# 個人ポートフォリオ 計算ルール (iOS / Android / Web 共通)

作成: 2026-10-13 · 状態: **案 (確認待ち)**
共通テストケース: [`portfolio_calc_cases.json`](portfolio_calc_cases.json) — 3 プラットフォームとも同じ入力で同じ数字になること。

方針: 損益率は **元本比 1 種類だけ** (時間加重 TWR・年率換算は出さない)。元本を利益として数えない。

## 1. 用語と式

| 項目 | 式 |
|---|---|
| 保有原価 (円) | Σ 保有ロット 原価。原価 = 投資額 (invest_amount、無ければ 数量 × 取得単価) × 取得時為替 (円建ては 1) |
| 評価額 (円) | Σ 保有ロット 数量 × 最新終値 × 今日の USD/JPY (円建ては 1) |
| 実現損益 (円) | Σ 売却記録 realized_pnl_jpy (= 売却額 − 売った分の原価) |
| 売却済み原価 (円) | Σ 売却記録 cost_basis_jpy |
| **元本** | 保有原価 + 売却済み原価 |
| **損益** | (評価額 − 保有原価) + 実現損益 |
| **損益率 (元本比)** | 損益 ÷ 元本 × 100 |

### ロットの扱い
- **取得時為替**: ロットに保存した buy_fx_rate を使う。無い USD ロットは「円換算できない」として **損益・元本から除外** (固定レート・今日のレートで埋めない)。
  画面の評価額合計には、その分の今の時価を参考として足す (損益には入れない)。
- **通貨**: 上場市場の通貨 (米国上場 = USD)。ティッカーの形だけで推測しない。
- **株式分割**: stock_splits の ex_date が取得日より後の分割は、数量 × 比率・単価 ÷ 比率 にして今の単位にそろえる (原価は変わらない)。
  stock_daily_prices の終値は分割調整済み (285A.T 2026-09-29 1:3 で確認) なので、過去の終値はそのまま使う。

## 2. 推移 (日ごとの 評価額・原価)
- 最初の取得日 (最大 400 日前) から今日まで毎日。
- その日に持っていたロット: 原価を足し、評価額 = 数量 × その日の終値 (無ければ直近の終値、それも無ければ原価) × その日の USD/JPY。
- **売ったロットも 取得日 ≤ 日 < 売却日 の間は持っていたものとして数える** (売却記録の buy_lots。無い古い記録は数えない)。
- 日ごとの 元本・損益 = 上の評価額・原価 + その日までに売った分の 売却済み原価・実現損益。今日の点はライブの値に置き換える。
- サーバーの user_portfolio_history は推移の計算に使わない (削除・誤入力のロットが残った日がある)。

## 3. 期間の変化 (今月の変化 = 1 か月)
- 基準点 = 1 か月前の日以前で最後の点。
- 変化額 = 今の損益 − 基準点の損益 (買付・入金・売却そのものは含まれない)。
- 変化率 = 変化額 ÷ 今の元本 × 100。

## 4. 売却記録の buy_lots (新しい列, nullable)
`user_stock_realized_trades.buy_lots` / `user_fund_realized_trades.buy_lots` (jsonb)
`[{"buy_date":"yyyy-MM-dd","qty":<売却時点の単位>,"cost_jpy":<円>}]` — 売却で消費したロット (先入先出の順)。
書くのは売却機能を持つクライアント全部 (現在は iOS のみ。Web に売却を入れるときも同じ形式で)。

## 5. 現状との差 (2026-10-13 時点)

| 項目 | iOS / Android | Web (MoneyMart2.0 最新ブランチ 10/05) |
|---|---|---|
| 損益に実現損益 | 含む | **含まない** (評価額 − 投資額 のみ) |
| 元本 | 保有原価 + 売却済み原価 | 保有原価のみ |
| USD の取得時為替 | ロットの buy_fx_rate、無ければ除外 | 取得日の為替表、無ければ **固定レート** |
| 株式分割 | 調整あり | **調整なし** (分割後に評価額が 1/比率 になる) |
| 推移チャート | 保有ロット × 日別終値 | 既定は **元本→現在の直線補間** (保有タブのみ実値) |
| 売ったロットの推移 | 数えない (→ §2 で変更) | 数えない |
| 今月の変化 | あり | なし |

※ Web の「3 か月実績」は 積立シミュレーターの想定利回り (TOPIX/日経 ETF) で、ポートフォリオの損益率ではない。
※ Web はどのブランチが本番か要確認。
